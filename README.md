# <img width="50" height="50" alt="warehouse" src="https://github.com/user-attachments/assets/3424c374-6c77-4e99-903e-c73272abe40b" /> DATA WAREHOUSE and ANALYTICS PROJECT #


Welcome to the **Data warehouse and Analytics Project** repository
This project demonstrate the design and implementation of a modern data warehouse for integration data from multiple sources such as CRM and ERP system.

This project follows a Medallion Architecture consisting of Bronze, Silver, and Gold layers. The processed data is modeled using a Star schema and prepared for reporting and analytical purpose.

## <img width="30" height="30" alt="target" src="https://github.com/user-attachments/assets/b9aad50d-e2e2-4438-a30d-b9e08dc62fba" /> ``Business Problem`` ##

The company has data coming from different sources such as CRM and ERP.
The data is stored in different format, contain many duplicates, missing values and inconsistent formats. The objective of this project is to build a centralized data warehouse that is cleaned, integrated, transforms and organized data so that business user can easily analyze the data and draw meaningful insights.

## <img width="30" height="30" alt="pipe" src="https://github.com/user-attachments/assets/1cfb060a-dfff-4159-862f-5edb427b80ec" /> ``ETL Pipeline`` ##

Extract: Collect data from CRM, ERP and CSV source.

Transform: Clean, validate, standardize, integrate and enrich the data.

Load: Load processed data into the appropriate warehouse layers.

## <img width="30" height="30" alt="networks" src="https://github.com/user-attachments/assets/e9e5dccd-b08e-4171-8af1-dc5c898802e4" /> ``Data architecture`` ##

1.Bronze Layer: Stores raw data from the source system. Data is integrated from csv files into SQL server database.

2.Silver layer: This layer includes data cleaning, standarization and normalization process to prepare data for analysis.

3.Gold layer: House business ready data modeled into a star schema required for reporting and analytics
